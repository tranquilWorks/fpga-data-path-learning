## Model and retained deterministic contract

- Inputs: `requiredHigh` in `1..3`, shared independent input-HIGH probability `p` in `0..1`, selected zero-based address in `0..7`, and fault address `-1` or `0..7`.
- Address convention: `address = 4*A + 2*B + C`; A is the most-significant bit and C is the least-significant bit. MATLAB row index is `address+1`.
- Fixed exhaustive addresses: `000` through `111`, exactly eight unique rows.
- Baseline: `k=2`, `p=0.5`, selected address `3`, no fault.
- Baseline output vector: `[0 0 0 1 0 1 1 1]`.
- Independent baseline equation: `Y=(A AND B) OR (A AND C) OR (B AND C)`.
- Sweep 1 invariant: asserted rows for `k=[1 2 3]` are `[7 4 1]` for OR, majority, and AND.
- Sweep 2 invariant: the mapping remains fixed and `P(Y=1)=3p^2-2p^3` for majority under the stated independent, identical-`p` assumption.
- Broken case: LUT address `6` (`ABC=110`) alone is flipped. It creates exactly one mismatch with weighted probability `p^2(1-p)`.
- Resource contract: the model always returns eight rows and an 8-by-8 numeric truth-table matrix. Experiment sweeps contain 3 and 21 cases; the interactive probability curve contains 51 cases per bounded callback update.

The Python oracle independently constructs addresses, Boolean equations, row weights, and faults. Static tests also pin the corresponding MATLAB source expressions so source drift cannot leave the oracle green unnoticed. This still does not execute or translate MATLAB semantics, so MATLAB-model numerical validation remains explicitly unperformed.

### Interactive controls

- Required-HIGH threshold spinner: integer `k` from 1 through 3.
- Input-HIGH probability slider: `p` from 0 through 1.
- Selected input-address spinner: integer address 0 through 7.
- Fault checkbox: disabled or flip fixed address 6 (`110`).

Every control has a changed callback; the probability slider also has a changing callback. The callback captures `@model` while the module path is active, and figure cleanup targets only P02-named figures.

### Metrics and units

- Input address: unitless integer, also labeled by binary `ABC`.
- A, B, C, specified output, and LUT output: binary logic level.
- Required-HIGH threshold, HIGH-input count, asserted rows, and mismatches: counts.
- `p`, row probability, `P(Y=1)`, asserted-row fraction, and mismatch probability: unitless fractions.

The lesson explicitly states that asserted-row fraction is a runtime probability only under uniform row occurrence and that the probability curve assumes independent inputs sharing one HIGH probability.
