## Model and retained deterministic contract

- Inputs: fractionBits in 0 through 8, integerBits in 0 through 4 excluding sign, and selectedSample in 1 through 25 are finite real numeric integer scalars normalized to double after validation; brokenWrap is logical or numeric 0 or 1 and is normalized to logical.
- Fixed stimulus: 25 sorted unitless samples from -2.9 through 2.9, including ordinary decimals, exact half-LSB ties, values near narrow-format rails, and overload values.
- Format: one sign bit and W = 1 + I + F; Delta = 2^-F; signed codes [-2^(W-1), 2^(W-1)-1]; represented values [-2^I, 2^I-Delta].
- Rounding: sign(x/Delta) times floor(abs(x/Delta) + 0.5), so exact half-LSB ties move away from zero.
- Healthy overflow: clamp the rounded code to the two's-complement endpoints before rescaling by Delta.
- Broken overflow: wrap the rounded code modulo 2^W; the healthy saturated result remains separately retained as the reference.
- Baseline: F=3, I=2, selected sample 16, healthy saturation policy. W=6, Delta=0.125, range [-4,3.875], zero overflow, maximum absolute error 0.0625, and selected input 0.31 maps to code 2, output 0.25, error -0.06.
- Fractional-bit sweep: F=0 through 8 at I=2. LSB values are 1 through 1/256, word lengths are 3 through 11, the fixed vector never overflows, every error remains within half an LSB, and RMS error decreases for this stimulus.
- Integer-bit sweep: I=0 through 4 at F=3. LSB remains 0.125; ranges expand from [-1,0.875] through [-16,15.875]; overload counts are [13,5,0,0,0]; formats with I at least 2 produce the same outputs for the fixed vector.
- Broken case: at F=3, I=1, overloaded sample indices are [1,2,23,24,25]. Saturated outputs are [-2,-2,1.875,1.875,1.875]; wrapped outputs are [1.125,1.875,-2,-1.875,-1.125]. All five are saturation-reference mismatches and opposite-sign direction reversals; all 20 non-overflow samples remain unchanged.
- Resource contract: each call allocates fixed 25-row vectors; exposed formats span one through 13 modeled bits and at most 8192 legal codes. These are bounded model properties, not measured FPGA utilization.

The Python oracle independently reconstructs rounding, code limits, saturation, modulo wrap, scaling, errors, and selection across all 45 format combinations and malformed cases. Static tests pin the corresponding MATLAB formulas, validated numeric-class normalization, a retained typed-input equivalence assertion, data orientation, control bounds, isolation assertions, source-level absence of toolbox, dynamic, or external operations, and marker-only presentation of sparse sample mappings. This still does not execute or translate MATLAB semantics.
