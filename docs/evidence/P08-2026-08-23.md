## Model and deterministic contract

- Inputs: `tuningWord` is an integer `0..2047`; `phaseAddressBits` is an integer `3..12`; `initialPhaseCode` is an integer `0..4095`; `brokenIncrementTruncation` is logical or numeric zero/one. Accepted integer classes normalize to double/logical after finite, real, scalar, integer, and range validation.
- Fixed teaching assumptions: accumulator width `B=12`, modulus and record length `M=4096`, and sample clock `f_s=100 MHz`. The clock is used only for unit conversion.
- Healthy recurrence: `phase[n] = mod(phi0+n*K,4096)`. Requested and actual phase steps match `K`; `f_out=K*f_s/4096`; the minimum frequency resolution is `24.4140625 kHz/code`.
- Lookup boundary: `P` most-significant accumulator bits select `2^P` explicit floating-point sine/cosine phase entries. The healthy path truncates phase only after full-width accumulation. Lookup phase step is `360/2^P` degrees.
- Baseline: `K=411`, `P=8`, `phi0=0`; frequency `10.0341796875 MHz`; phase step `36.123046875 degrees/sample`; 256 lookup entries; first phase codes `[0,411,822,1233,1644,2055,2466,2877,3288,3699,14,425]`; first addresses `[0,25,51,77,102,128,154,179,205,231,0,26]`; maximum truncation error `1.318359375 degrees`; period 4096 samples.
- Wrap convention: `wrapCount` counts all 4096 modeled transitions from each stored state to its next state, including the terminal transition from stored sample 4095 to unrecorded sample 4096. Baseline `wrapCount=411`; only 4095 transitions connect pairs of stored states, so `withinRecordWrapCount=410`. The model exposes both event vectors, both counts, transition counts, and terminal next phase explicitly.
- Initial-phase wrap partition: changing `phi0` does not change the full-transition wrap total or frequency, but it can move one wrap between the 4095 stored-state transitions and the terminal transition. For required `K=411`, the terminal transition wraps through `phi0=410` and stops wrapping at `phi0=411`; for broken applied `K=400`, the corresponding boundary is `phi0=399 -> 400`. Both paths return exactly to `phi0` after all 4096 transitions.
- Tuning sweep: output frequency, phase step, full-transition wraps, carrier bin, and period change with `K`; lookup entries, accumulator width, clock, initial phase, and allocation remain fixed. At `phi0=0`, full-transition wraps equal `K`, while stored-state discontinuities equal `max(K-1,0)` because the terminal transition is excluded.
- Address sweep: lookup entries double from 8 through 4096 as `P=3..12`; maximum phase error follows `(2^(12-P)-1)*360/4096`; full phase recurrence, `K`, frequency, clock, initial phase, and record size remain fixed. At `P=12`, lookup phase equals accumulator phase and truncation/waveform error is zero.
- Spectrum contract: one coherent 4096-sample complex-output FFT reports its carrier and phase-truncation spurs. Baseline modeled SFDR is `48.07535746411204 dB`. Finite SFDR is reported only when the largest spur exceeds the declared `-240 dBc` numerical floor. Otherwise `recordSfdrDb=Inf`, meaning no modeled spur resolved above the floor rather than infinite physical performance. Plotted dBc data is clamped to that same floor.
- Broken case: at `K=411`, `P=8`, the fault clears the four low increment bits before accumulation, applying `K=400`. The tone becomes `9.765625 MHz`, error `-268.5546875 kHz`, full-transition wraps become 400, stored-state discontinuities become 399, and the accumulator period shortens to 256 samples. Reference recurrence/output, lookup allocation, clock, and record bounds remain unchanged.
- Inert fault limits: the switch is behaviorally inert when `K` is divisible by the lookup truncation factor, at DC, or at full `P=12` addressing. The interactive checkbox clears before disabling at those limits.
- Resource contract: exactly 4096 stored samples and spectrum bins; at most 4096 lookup phase entries and 8192 paired sine/cosine table values. All loops and arrays are input-bounded. These are model allocation counts, not BRAM, area, power, or timing evidence.

`tests/test_p08_module.py` implements the recurrence, table, phase/waveform errors, wrap conventions, periods, and a radix-2 FFT independently rather than parsing MATLAB results. It validates the two sweeps, exact baseline/fault values, both adjacent initial-phase terminal-wrap thresholds, a representative 11-by-10 healthy/fault grid, malformed input/recovery behavior, resource bounds, baseline SFDR, and the full-address numerical-floor limit. A separate read-only NumPy calculation checked dominant carrier bins across 260 representative healthy/fault cases with zero mismatches. Static tests pin the corresponding MATLAB expressions and prohibit presentation in the model, opaque toolbox use, random/external/stateful/asynchronous behavior, and unbounded `while` loops. These checks do not execute MATLAB semantics.
